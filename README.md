# Bid Check

A working demo built for an Ajaia Entrepreneur in Residence assessment. It shows the first promise of the AI Government Proposal Writer described at [ajaia.ai](https://ajaia.ai/ai-powered-solutions/product-page/ai-government-contract-proposal-writing-platform): an RFP goes in, a compliance matrix comes out.

- **Live page:** https://termicapital.github.io/bid-check-demo/
- Runs entirely in the browser. Nothing you paste is sent anywhere.
- Requirement extraction uses fixed language rules, not Ajaia's AI.
- All sample data is fictional.
- Not an official Ajaia page or product.
